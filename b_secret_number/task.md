# 🕵️ Задача: Перехват сообщений

### Легенда
Валентина и Дмитрий обмениваются секретными сообщениями. Каждое сообщение содержит одно число — настоящую информацию, которой они хотят поделиться.

Чтобы защитить данные от перехвата, они заранее договорились о секретном простом числе $P$. Перед отправкой сообщения отправитель не передаёт настоящее число $x$ напрямую. Вместо этого он вычисляет замаскированное значение:

$$m = x \cdot P$$

Таким образом, каждое перехваченное сообщение — это произведение общего секретного простого числа $P$ и некоторого настоящего числа $x$ (числа $x$ меняются от сообщения к сообщению и никогда не раскрываются).

**Ваша роль:** Вы перехватчик. Вы захватили несколько замаскированных сообщений. Ваша задача — восстановить секретное простое число $P$.

---

### Условие задачи
Даны $n$ перехваченных сообщений $m_1, m_2, \dots, m_n$, где каждое:

$$m_i = x_i \cdot P$$

Для некоторого положительного целого $x_i$ (вам неизвестного) и одного и того же секретного простого числа $P$, **восстановите число $P$**.

**Гарантируется, что:**
* $P$ — простое число.
* Каждое сообщение делится на $P$.
* Числа $x_i$, взятые вместе, не имеют общего простого множителя.

---

### Ограничения
* $2 \le n \le 100$
* $2 \le m_i \le 10^{18}$
* $2 \le P \le 10^{18}$

---

### Формат входных данных
1. **Первая строка** содержит одно целое число $n$ — количество перехваченных сообщений ($2 \le n \le 100$).
2. **Вторая строка** содержит $n$ целых чисел, разделённых пробелами: $m_1, m_2, \dots, m_n$ — перехваченные сообщения ($2 \le m_i \le 10^{18}$).

### Формат выходных данных
Выведите одно целое число — секретное простое число $P$.
