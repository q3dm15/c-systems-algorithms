# Проверка API-токенов (Алгоритм Луна)

## Легенда
ИИ-платформа выдаёт API-токены своим агентам. Чтобы выявлять опечатки и явно поддельные токены до выполнения любого дорогостоящего поиска, каждый токен заканчивается контрольной цифрой, вычисленной с помощью алгоритма Луна (та же контрольная сумма, что используется в номерах кредитных карт).

Токен — это строка десятичных цифр, возможно записанная с разделителями `-` или пробелами для удобочитаемости (например, `4539-1488-0343-6467`). Разделители не несут смысла и должны игнорироваться. После удаления разделителей токен должен состоять только из цифр.

Шлюз безопасности хочет быстро отклонять любой токен, не прошедший контрольную сумму.

## Алгоритм Луна
Дана строка цифр \(d_1 d_2 \dots d_n\) (слева направо), проверка выполняется так:
1. Начиная с самой правой цифры и двигаясь влево, удваивайте значение каждой второй цифры (то есть цифры на позициях: 2-я справа, 4-я справа и так далее).
2. Если при удвоении цифры получается число больше 9, вычтите из него 9 (что эквивалентно сложению двух десятичных цифр произведения).
3. Просуммируйте все получившиеся значения (удвоенные-и-скорректированные цифры вместе с нетронутыми цифрами).
4. Токен действителен тогда и только тогда, когда эта сумма кратна 10.

## Задача
Вам дано \(M\) кандидатов-токенов. Для каждого токена:
1. Удалите все символы-разделители `-` и пробелы.
2. Если оставшаяся строка пуста или содержит любой нецифровой символ, токен считается **INVALID**.
3. Иначе примените проверку Луна и выведите **VALID**, если контрольная сумма проходит, и **INVALID** в противном случае.

## Формат ввода
* Первая строка содержит одно целое число \(M\) — количество токенов (\(1 \le M \le 100\,000\)).
* Каждая из следующих \(M\) строк содержит один кандидат-токен. Строка токена имеет длину от 1 до 100 символов и может содержать цифры, дефисы `-` и пробелы. Токены заданы дословно (токен никогда не имеет ведущего/завершающего содержимого, кроме описанных разделителей).

## Формат вывода
Выведите \(M\) строк. Строка \(t\) должна содержать `VALID` или `INVALID` для \(t\)-го токена.

---

### Пример входных данных
```text
3
4539-1488-0343-6467
1234 5678 1234 5678
4539-1488-0343-646A
```

### Пример выходных данных
```text
VALID
INVALID
INVALID
```
